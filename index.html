WSDM '27

TaskMap · Task-Conditioned LLM Adaptation

Second author · WSDM 2027 Findings

TaskMap: Task-Conditioned LLM Adaptation in a Shared Orthogonal Basis. Each task's adaptation is a set of coefficients in shared, fixed orthogonal bases, which gives the weight updates identifiable low-dimensional coordinates.

Studies where cross-task interference in shared adapters comes from, on a frozen backbone across heterogeneous tasks and unseen tasks described only in text.
